# Coco Island 3D

ブラウザで遊べる、マリオ風の3Dアクションゲームです。`index.html` をブラウザで開くだけで遊べます（Three.js を CDN から読み込みます）。

## ステージ

| ステージ | 内容 |
| --- | --- |
| 1-1 ココ島のてっぺん | 動く足場、ジャンプ台、エレベーターで島を登り、頂上のパワースターを取る |
| 1-2 マグマとりで | 溶岩の上の動く足場、回転するファイアバー、落ちてくるドッスンを越えて、ボス「キングマッシュ」を倒す |

1-1 をクリアすると、タイトル画面から 1-2 を直接選べるようになります。

## ボス：キングマッシュ

- 体力 3。頭にトゲの王冠があり、普段は踏むとこちらがダメージを受けます
- 踏めるのは、**柱に突進してぶつかった後**か、**連続ジャンプ攻撃の後でフラフラしている間**だけ（ヒップドロップなら2ダメージ）。柱にぶつかると約4秒、ジャンプ攻撃の後は約3秒ピヨります
- 着地のたびに衝撃波が広がるので、ジャンプでかわすか柱の上に逃げる
- 柱は横の段差ブロックから普通のジャンプで登れます。柱はボスより高いので、ピヨっているボスに上から飛び降りて踏めます
- 体力が残り1になると怒って速くなり、手下を呼びます
- ミスするとボスの体力は全回復します

## 操作

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | W A S D / 矢印キー | 左スティック |
| ジャンプ | Space | A ボタン |
| ヒップドロップ（空中で） | Shift | B ボタン |
| カメラ回転 | Q / E、マウスドラッグ | 画面ドラッグ |

- 着地直後にジャンプを続けると二段・三段ジャンプ
- コイン50枚ごとに残機 +1
- スターを取ると、ココがくるっと2回転してからスターを高く掲げます（カメラが正面に回り込みます）
