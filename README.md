# Coco Island 3D

ブラウザで遊べる、マリオ風の3Dアクションゲームです。`index.html` をブラウザで開くだけで遊べます（Three.js を CDN から読み込みます）。

## 遊び方

島をかけ上がって、てっぺんにあるパワースターを手に入れるとクリアです。

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | W A S D / 矢印キー | 左スティック |
| ジャンプ | Space | A ボタン |
| ヒップドロップ（空中で） | Shift | B ボタン |
| カメラ回転 | Q / E、マウスドラッグ | 画面ドラッグ |

- 着地直後にジャンプを続けると二段・三段ジャンプ（ジャンプを長押しすると高く跳べます）
- キノコ兵は上から踏むか、ヒップドロップの衝撃波で倒せます。横から当たると体力が減ります
- ？ブロックは下から叩くとコインが出ます
- 赤白のジャンプ台で雲の上へ。中間地点の旗に触れるとチェックポイントになります
